# Contributing

This is an archived research harness: it is not being developed, and a change is worth making only
if it keeps a published result checkable.

The practice is written down in [`docs/9_IMPLEMENTATION.md`](docs/9_IMPLEMENTATION.md) — how to run
the gate, the model server flags, how to add a corpus task, and the work-record rule. The rules that
kept the results trustworthy, which any change must preserve, are
[`docs/3_REQUIREMENT.md`](docs/3_REQUIREMENT.md).

`docs/` states the current fact; `.scratch/` holds the narrative behind it.
